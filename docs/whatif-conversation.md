# Unified What-if

상단 What-if 하나에서 시나리오 대화, 접이식 직접 입력, 결과표, 기존 관측 분석/맵 예측 설정에 접근합니다.

개인 Fab Copilot 연결을 공유합니다. LLM 연결 후 최근 4회 문답과 실행 조건을 전달해 후속 질문을 해석합니다. 모델은 검증된 catalog/분석/시뮬레이션 도구만 사용할 수 있습니다. 질문당 시뮬레이션 최대 2회, 기존 worker 시간 제한과 입력 범위가 적용됩니다. 도구가 템플릿 기반 가상 LOT를 생성하며 실제 데이터/생산계획은 변경하지 않습니다. 모델이 없는 경우 4개 명시적 예시만 규칙 기반 실행하며 AI 응답이 아님을 표시합니다. 자유 입력은 연결을 안내합니다.

LLM 설정 URL, 키, 모델은 기존 설정을 공유하고 키를 저장하지 않습니다. 대화도 현재 화면 메모리에만 유지합니다. 새 대화는 문맥과 결과를 지웁니다. 계산 성공/실패와 별개로 실제 품질 승인/홀드 해제/장비 증설은 수행하지 않습니다. 실제 사내 LLM 연결은 이 개발 환경에서 검증하지 않았습니다.
