# 내 관리 즐겨찾기

탐색·필터 맨 위에서 설정/저장/원클릭 적용/삭제. 로컬 브라우저 저장이며 사번 동기화가 아닙니다. 최대 20개, 항목별 100값. LOT ID·LOT CODE·FAB·공정명 또는 OPER ID·장비 ID는 쉼표 구분 exact match입니다. 항목 내 OR, 항목 간 AND. 빈 항목은 전체.

현재 라우트, 검색, FAB, 연구 전용, AREA 강조, 장비 검색도 같이 저장합니다. 시점은 저장하지 않으며 재생 시점의 현재 위치로 관리 조건을 다시 평가합니다. 관리 장비 조건은 이동 중/OUT 랏을 제외합니다. 즐겨찾기 조건 해제는 기존 화면 필터를 유지합니다. 동일 이름 저장은 해당 즐겨찾기를 교체합니다. 삭제는 적용 상태를 바꾸지 않습니다.

Copilot 규칙 알림은 현재 표시 states에 AREA·장비 검색 조건을 추가로 적용해 WIP를 재집계합니다. DOWN 알림은 그 범위 내 현재 재공이 지정된 장비만 포함하며, 필터가 바뀌면 기존 말풍선을 즉시 지웁니다. 품질 승인 또는 실제 해제/장비 제어는 수행하지 않습니다. What-if는 기존의 전체 WIP 독립 계산이며 즐겨찾기로 범위를 제한하지 않습니다.
